Инструкция по настройке
GigaChat (ИИ)
  1. Зарегистрируйтесь на developers.sber.ru
  2. Создайте проект и получите Authorization Key
  3. Скопируйте ключ и введите его в форму выше
HH.ru
  1. Зарегистрируйте приложение на dev.hh.ru
  2. Скопируйте Client ID и Client Secret
  3. Введите их в форму выше
  4. Укажите Redirect URI в настройках приложения на HH.ru
SuperJob
  1. Зарегистрируйте приложение на api.superjob.ru
  2. Скопируйте Client ID и Client Secret
  3. Введите их в форму выше
  4. Укажите Redirect URI в настройках приложения на SuperJob
Как это работает для пользователей:
  1. Пользователь нажимает "Опубликовать на HH.ru" в своём резюме
  2. Открывается страница HH.ru с запросом разрешения
  3. Пользователь входит в свой аккаунт HH.ru и нажимает "Разрешить"
  4. После этого резюме автоматически публикуется
