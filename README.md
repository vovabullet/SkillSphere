# Платформа для создания резюме

Веб-платформа для создания и управления профессиональными резюме с AI-ассистентом, возможностью экспорта в PDF и интеграцией с популярными площадками трудоустройства (HH.ru, SuperJob, LinkedIn).

## Возможности

- ✅ Регистрация и аутентификация пользователей
- ✅ Создание и редактирование резюме
- ✅ 4 профессиональных шаблона дизайна (Classic, Modern, Minimal, Tech)
- ✅ Загрузка фотографий (JPG, PNG, GIF, максимум 10MB)
- ✅ Экспорт резюме в PDF формат
- ✅ Предварительный просмотр
- ✅ AI-ассистент на базе GigaChat для улучшения текста
- ✅ Интеграция с HH.ru, SuperJob и LinkedIn

## Технологии

**Backend:**
- Flask 3.x - веб-фреймворк
- SQLAlchemy - ORM для работы с базой данных
- Flask-Login - управление сессиями
- Flask-WTF - валидация форм с CSRF защитой
- Werkzeug - хеширование паролей

**Frontend:**
- Bootstrap 5.3.0 - адаптивный дизайн
- Vanilla JavaScript (ES6+)
- Custom CSS с градиентами

**Дополнительно:**
- SQLite 3 - база данных
- WeasyPrint - генерация PDF
- GigaChat API (Сбер) - AI-функции

## 🚀 Установка и запуск на локальном ПК

### Шаг 1: Установка Python

1. Скачайте Python 3.10 или выше с официального сайта: https://www.python.org/downloads/
2. При установке **обязательно** отметьте галочку "Add Python to PATH"
3. Проверьте установку, открыв командную строку (cmd) и введя:
```bash
python --version
```

### Шаг 2: Скачивание проекта

Скачайте проект одним из способов:

**Вариант А: Через Git**
```bash
git clone <URL_вашего_репозитория>
cd <название_папки_проекта>
```

**Вариант Б: Скачать ZIP**
1. Скачайте проект как ZIP-архив
2. Распакуйте в любую папку
3. Откройте командную строку в этой папке

### Шаг 3: Установка зависимостей

Откройте командную строку в папке проекта и выполните:

```bash
pip install -r requirements.txt
```

Это установит все необходимые библиотеки:
- Flask
- SQLAlchemy
- Flask-Login
- Flask-WTF
- WeasyPrint
- И другие

### Шаг 4: Настройка GigaChat API (для AI-функций)

#### Где получить ключ:
1. Зарегистрируйтесь на https://developers.sber.ru/
2. Создайте проект
3. Получите **Client Secret** - это ваш API ключ

#### Как вставить ключ:

**Способ 1: Через переменные окружения (рекомендуется)**

**Windows:**
1. Нажмите Win + R
2. Введите `sysdm.cpl` и нажмите Enter
3. Перейдите на вкладку "Дополнительно"
4. Нажмите "Переменные среды"
5. В разделе "Переменные среды пользователя" нажмите "Создать"
6. Имя переменной: `GIGACHAT_KEY`
7. Значение: вставьте ваш ключ
8. Нажмите OK
9. **Перезапустите командную строку**

**Linux/Mac:**
Откройте файл `~/.bashrc` или `~/.zshrc` и добавьте:
```bash
export GIGACHAT_KEY="ваш_ключ_здесь"
```
Сохраните и выполните:
```bash
source ~/.bashrc
```

**Способ 2: Временно в командной строке**

**Windows (CMD):**
```bash
set GIGACHAT_KEY=ваш_ключ_здесь
```

**Windows (PowerShell):**
```bash
$env:GIGACHAT_KEY="ваш_ключ_здесь"
```

**Linux/Mac:**
```bash
export GIGACHAT_KEY="ваш_ключ_здесь"
```

**Способ 3: Создать файл .env (если используете python-dotenv)**
Создайте файл `.env` в корневой папке проекта:
```
GIGACHAT_KEY=ваш_ключ_здесь
SESSION_SECRET=любая_случайная_строка
```

### Шаг 5: Инициализация базы данных

Если база данных еще не создана, выполните миграции:

```bash
python migrate_add_customization.py
python migrate_add_photo.py
```

### Шаг 6: Запуск приложения

Выполните команду:

```bash
python run.py
```

Вы увидите сообщение:
```
* Running on http://127.0.0.1:5000
```

Откройте браузер и перейдите по адресу: **http://localhost:5000**

### Шаг 7: Первое использование

1. На главной странице нажмите "Регистрация"
2. Создайте аккаунт (введите имя, email, пароль)
3. Войдите в систему
4. Нажмите "Создать резюме"
5. Заполните данные и загрузите фотографию
6. Используйте AI-функции для улучшения текста
7. Экспортируйте в PDF

## 📦 Создание .exe файла (для Windows)

Чтобы создать исполняемый файл (.exe), который можно запустить на любом компьютере без установки Python:

### Шаг 1: Установка PyInstaller

```bash
pip install pyinstaller
```

### Шаг 2: Создание файла запуска

Создайте файл `start.py` в корневой папке проекта с содержимым:

```python
import os
import sys
from app import create_app, db

if __name__ == '__main__':
    app = create_app()
    
    with app.app_context():
        db.create_all()
    
    app.run(host='127.0.0.1', port=5000, debug=False)
```

### Шаг 3: Создание .exe

Выполните команду:

```bash
pyinstaller --onefile --add-data "app/templates;app/templates" --add-data "app/static;app/static" --name "ResumeApp" start.py
```

Это создаст:
- Папку `dist/` с файлом `ResumeApp.exe`
- Папку `build/` (временные файлы)
- Файл `ResumeApp.spec`

### Шаг 4: Подготовка для распространения

1. Скопируйте из папки `dist/` файл `ResumeApp.exe`
2. Создайте новую папку для распространения
3. Скопируйте в нее:
   - `ResumeApp.exe`
   - Папку `app/` (с templates, static)
   - Папку `instance/` (будет создана при первом запуске)
   - Файл `config.py`
   - Файлы миграций (если нужны)

### Шаг 5: Запуск .exe

Просто запустите `ResumeApp.exe` двойным кликом. Приложение откроется на http://localhost:5000

### Важные примечания:

⚠️ **WeasyPrint и .exe:**
WeasyPrint может не работать корректно в .exe из-за зависимостей. Для создания полноценного .exe рекомендуется:

1. Использовать альтернативу для PDF (например, ReportLab или pdfkit)
2. Или создать установщик с помощью Inno Setup / NSIS
3. Или запускать приложение через Python (без .exe)

⚠️ **Рекомендация:**
Для веб-приложений лучше не создавать .exe, а:
- Развернуть на локальном сервере
- Или использовать облачный хостинг (Heroku, PythonAnywhere, Railway)
- Или создать Docker контейнер

### Альтернатива: Простой BAT-файл для запуска

Создайте файл `start.bat`:

```batch
@echo off
python run.py
pause
```

Пользователь просто запускает этот файл, и приложение стартует.

## 🔧 Решение проблем

### Ошибка: "python не является внутренней командой"
- Python не добавлен в PATH
- Переустановите Python с галочкой "Add Python to PATH"

### Ошибка: "No module named 'flask'"
- Зависимости не установлены
- Выполните: `pip install -r requirements.txt`

### AI-функции не работают
- Проверьте, что GIGACHAT_KEY установлен
- Выполните в командной строке: `echo %GIGACHAT_KEY%` (Windows) или `echo $GIGACHAT_KEY` (Linux/Mac)
- Ключ должен отобразиться

### Не открывается страница в браузере
- Убедитесь, что порт 5000 свободен
- Проверьте вывод консоли на наличие ошибок
- Попробуйте другой порт в файле `run.py`: `app.run(port=8080)`

### Ошибка при генерации PDF
- Проверьте, что WeasyPrint установлен корректно
- На Windows может потребоваться установка GTK3: https://weasyprint.readthedocs.io/en/stable/install.html#windows

## Метрики

1. Для запуска Grafana с метриками необходимо из корня проекта выполнить команду `docker-compose up -d` (убедитесь, что у вас запущен Docker или Docker-Compose)
2. После запуска приложения, дашборд с метриками будет находиться на адресу `http://localhost:3000/`
3. Введите логин и пароль admin
4. Перейдите на вкладку Dashboards и выберите "SkillSphere — Резюме по профессиям"

## Логи и ELK

В проект добавлен стек ELK (Elasticsearch + Logstash + Kibana) через `docker-compose`.

1. Убедитесь, что заполнены переменные в `.env`:
   - `APP_LOG_LEVEL` (по умолчанию `INFO`)
   - `APP_LOG_PATH` (по умолчанию `/var/log/skillsphere/app.log`)
   - `ELK_INDEX_PREFIX` (по умолчанию `skillsphere`)
2. Запустите инфраструктуру:
   ```bash
   docker-compose up -d
   ```
3. Сервисы будут доступны:
   - Elasticsearch: `http://localhost:9200`
   - Kibana: `http://localhost:5601`
4. В Kibana создайте Data View по шаблону: `skillsphere-*` (или вашему `ELK_INDEX_PREFIX`).
5. После генерации логов приложением они появятся в Elasticsearch через Logstash.

## 🆘 Поддержка

Если у вас возникли проблемы:
1. Проверьте раздел "Решение проблем" выше
2. Убедитесь, что все зависимости установлены
3. Проверьте, что Python версии 3.10 или выше
4. Убедитесь, что GIGACHAT_KEY настроен правильно (если используете AI)
5. Если не удается выполнить `docker-compose up -d`:
   1. Проверьте, что Docker запущен и работает. Сделать это можно командами: `docker --version` и  `docker ps` (если они что-то выводят, значит Docker запущен)
   2. Проверьте, что у Docker есть доступ к файлам проекта. Выполните следующие команды (Даёт полный доступ к папкам Grafana): 
`icacls "grafana" /grant:r "USERNAME:F" /t`
`icacls "grafana/provisioning" /grant:r "USERNAME:F" /t`
`icacls "grafana/dashboards" /grant:r "USERNAME:F" /t`, где USERNAME - это имя пользователя (узнать можно командой whoami)
